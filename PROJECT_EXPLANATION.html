1. Project Overview

IntelliDoc AI is an advanced document intelligence platform designed to transform how users interact with their documents. Moving beyond simple text extraction, it leverages state-of-the-art Large Language Models (LLMs) to provide interactive chatting, multimedia content creation (podcasts and slides), and autonomous research capabilities.

Key Capabilities:

  • Contextual PDF Chat: Ask questions directly to your documents.
  • Autonomous Agents: Perform complex tasks like flight searches or stock price analysis.
  • Multimedia Conversion: Turn PDFs into engaging 2-host podcasts or professional slide decks.
  • Visual Intelligence: Generate knowledge graphs from unstructured text.
  • Video Synergy: Process YouTube videos and chat with their transcripts.

2. System Architecture

The project employs a Hybrid Architecture to cater to different user needs:

Stack A: Streamlit (Rapid Prototyping)
A monolithic approach using app.py for an all-in-one Python-based interface. Ideal for quick local deployment and testing of individual features.

Stack B: React + Flask (Scalable Web App)
A modern client-server architecture. The Backend (Flask) handles LLM integrations, PDF processing, and Database management, while the Frontend (React + Vite) provides a premium, responsive user experience.

Intelligence Layer
The system interfaces with Ollama (Local LLMs) for privacy and Google Gemini / MiniMax for high-performance cloud processing.

5. Frontend Implementation (React)

The frontend is a modern React application built with Vite and Vanilla CSS, emphasizing a premium "Glassmorphic" look with vibrant colors and smooth transitions.

Architecture highlights:

  • Dynamic Routing: Uses React Router for seamless navigation between features.
  • Context Management: AuthContext.jsx handles global user state and persistence.
  • Responsive Sidebar: Unified control center for switching between Chat, Agent, and multimedia modes.
  • Premium UI: Custom CSS tokens for dark mode, glassmorphism, and subtle micro-animations.

API Integration (frontend/src/api.js)

Centralized module for communicating with the Flask backend.

import axios from "axios";
const API_BASE_URL = "http://localhost:5000/api";

export const chatWithBot = async (messages, pdfContext, model) => {
    const response = await axios.post(`${API_BASE_URL}/chat`, {
        messages, pdf_context: pdfContext, model
    }, { withCredentials: true });
    return response.data;
};

Key Pages

The frontend is divided into specialized pages for each core functionality:

  • ChatPage.jsx: Real-time chat interface with PDF context injection.
  • AgentPage.jsx: Visual terminal for observing autonomous agent "Thinking" and "Action" steps.
  • YouTubePage.jsx: Integrated video player with sidebar for summary and transcript chat.
  • PodcastPage.jsx: Studio-like interface for generating and playing AI conversations.
